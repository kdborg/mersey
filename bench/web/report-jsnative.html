Mersey — JS vs native

The same program as plain JavaScript and as native Mersey, in two arenas. Browser — each fork's own JS engine (js) vs the Mersey engine hosted natively in that fork (mersey), for Chromium (·cr), Firefox (·ff), Servo (·sv), Ladybird (·lb). Command line — Node, Bun and Deno running the JS twin vs the Mersey CLI running the Mersey twin (compute workloads only — Node has no DOM). Time is the self-timed workload loop (median, log scale, same checksum on every bar); memory is the process's peak/PSS delta. Platform: macos. A dimmed n/a row is honest absence (a fork that can't run that workload). This is report-pertech's js-vs-native cut, so there is no transpiled or WASM row to leave empty.
