Four command-line runtimes on the browser-free subset of the Mersey benchmark suite — the compute workloads whose Mersey twin imports only std:, so each has a line-for-line JavaScript twin that runs unchanged in Node, Bun and Deno. Every leg prints an identical checksum, so the times below measure the same computation four ways.

Method & caveats

Each workload runs as its own fresh process. Work is self-timed inside the language (performance.now / time.monotonic) after an in-process warm-up, so it isolates steady-state kernel throughput and excludes process startup. Wall is the whole /usr/bin/time invocation — startup, JIT warm-up and work together — i.e. what you actually wait for at the shell. Peak RSS is the macOS time -l "maximum resident set size".

The compute and calls checksums are exact int32 values; fcompute and mathk self-check with a boolean, because bit-identical float results across two independent code generators aren't guaranteed. Only these four workloads are browser-free — the rest of the suite needs a web host and can't run in a bare JS runtime either.
