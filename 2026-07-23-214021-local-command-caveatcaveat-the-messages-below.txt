  privileged actor; in Chromium there is no equivalent hook to call, so C++ work
  is required either way.

  Also relevant: Chromium's Runtime domain is implemented by v8_inspector, not
  Blink. Execution contexts there are real V8 contexts, so I can't publish a
  "Mersey" pseudo-context and get the dropdown for free the way I assumed when I
  wrote the design doc. That assumption was wrong, and I'd rather correct it
  now than build on it.

  Both routes need: a clean ReplTurn(String)/ReplCompletions() API in
